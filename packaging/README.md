# Building the desktop app

## macOS

```bash
.venv/bin/pip install -e ".[gui,build]"
PYTHON=.venv/bin/python packaging/build_macos.sh
```

Produces, in `dist/`:

- `Parameter Extractor.app` (~125 MB): double-click to run
- `ParameterExtractor-<version>-macOS-<arch>.dmg` (~60 MB): what you'd distribute

The build takes under a minute. Check the result without running an
extraction or spending API credit:

```bash
"dist/Parameter Extractor.app/Contents/MacOS/Parameter Extractor" --self-check --pdf some-paper.pdf
```

The self-check confirms the bundled prompts and vocabulary are present, the
PDF can be parsed and rendered, the system keychain is reachable, and (if
`ANTHROPIC_API_KEY` is set) that the API accepts the key and the configured
models exist. It uses the free models endpoint, so it costs nothing. Users can
run it too when reporting a problem.

### Architecture

The app is built for the Mac it's built on (`arm64` on Apple Silicon). An
Intel build needs an Intel Mac, or a universal2 Python and
`target_arch="universal2"` in the spec.

### Signing and notarization (needed before giving the app to others)

The build is only ad-hoc signed. That's fine on the machine that built it, but
on anyone else's Mac, Gatekeeper will refuse to open it ("can't be opened
because Apple cannot check it for malicious software"). A public release
needs:

1. An **Apple Developer Program** membership ($99/year) and a
   *Developer ID Application* certificate.
2. Signing: `codesign --deep --force --options runtime --timestamp --sign "Developer ID Application: <name> (<team id>)" "dist/Parameter Extractor.app"`
   (PyInstaller can also do this via `codesign_identity=` in the spec).
3. Notarization: `xcrun notarytool submit <dmg> --keychain-profile <profile> --wait`,
   then `xcrun stapler staple <dmg>`.

Also set a real `BUNDLE_ID` in `parameter_extractor.spec` first (reverse-DNS,
e.g. `edu.<institution>.parameter-extractor`). It identifies the app to macOS,
including for its keychain entry and saved preferences.

## Windows

PyInstaller doesn't cross-compile. On a Windows machine with Python 3.10+:

```bat
py -m venv .venv
.venv\Scripts\pip install -e ".[gui,build]"
.venv\Scripts\python -m PyInstaller --noconfirm --clean packaging\parameter_extractor.spec
```

This gives `dist\Parameter Extractor\Parameter Extractor.exe` (zip the
folder, or wrap it with an installer such as Inno Setup). Unsigned Windows apps
trigger a SmartScreen warning. A code-signing certificate removes it. Not yet
tested on Windows.

## Icon

`packaging/icons/` is generated by `python packaging/make_icon.py`
(placeholder art: a page with a data table). Replace the art and re-run it to
refresh `app.icns`, `app.ico`, `app.png` and the window icon in
`src/parameter_extractor/gui/resources/`.
