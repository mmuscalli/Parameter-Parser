# Prebiotic Chemistry vs "Prebio Chem DUPE" (prebiotic + Suggest-additions from the Sam Papers), 2026-11-08

**Setup.** 3 Sam papers with tabulated results (Ferris & Ertem 1993, Hirakawa 2025, Song 2024) x 2 packs x 3 runs =
18 live runs, Standard models, online lookups on, figures not digitized. Every suggested variable accepted (as "Add all
as suggested") into a throwaway registry per run -- nothing remembered. Runs interleaved (paper/pack repeats ~6 min
apart); costs re-priced where a structure step read a still-cached prefix. Consistency = mean pairwise share of one
run's filled cells another run of the same pack reproduces (rows paired by content; eval_references.score). Accuracy
judged by checking the values that differ against the papers.

DUPE's additions: stages product_structure (linkage_3_5_pct, oligomer_yield_pct, mean_oligomer_length_nt,
sequence_composition; always runs) and thermal_gradient_transport; exchangeable_cation (conditions), reaction_rate_mM_hr
(kinetics); a row rule for reviews; ~150 compounds (incl. junk: 'ab', 'b', 'a-P', 'A'/'G'/'U'/'C'/'T', 'DNA', 'RNA',
'DNase I', 'SYBR Green I', primed duplicates 2'/2', ppA and p2A both, the ambiguous 'TMP').

**Cost** (+$0.077/paper): product_structure runs on every paper (+$0.032), the larger cached prefix (+4.2K tokens:
two more tools, a bigger compound vocabulary; structure step +$0.012, every reading step a little more), kinetics output
7x larger with reaction_rate (+$0.012), thermal_gradient_transport where triggered.

**Valid parameters one pack has and the other lacks** (checked against the papers):
- DUPE: exchangeable_cation in Ferris (Li+, Na+, NH4+, Ca2+, Mg2+ -- Table II; 2 of 3 runs complete, 1 partial);
  3',5'/2',5' linkage in Ferris (2:1 and 3:1 -- stated; every run, under different names); ImpA 15 mM for the pure-ImpA
  reactions (0.015 M, stated; 2 runs -- prebiotic gave only the mixture shares); sequence_composition in Song (3/3, a
  real result); consistent compound names in Hirakawa (ribose / DAP / Borate in every run; the prebiotic pack's run 2
  switched to D-ribose / diamidophosphate -- split columns).
- Prebiotic: sampled_pH 8.5 in Hirakawa ("ending pH ~ 8.5", 3/3 runs; DUPE 0/3); product linkage / homopolymer
  composition / hydrolysis half-time in Song through accepted suggestions (valid; less stable names).
- Errors only DUPE made: dTMP written as 'TMP' (its vocabulary's TMP = trimetaphosphate in the Sam papers) in a Song run;
  ppA / pppA written as p2A / p3A (both in its vocabulary) in a Ferris run; longest_oligomer_detected_nt repeating
  max_oligomer_length_nt; reaction_rate_mM_hr and sampled_RCP_aq_rate_mM_hr (the same numbers twice, negative, likely
  derived, 1 run); a Song run planned as 8 rows with 0.0 values (consistency 57%).
- Errors only prebiotic made: adapter / standard DNA sequences as product columns in Song (2 runs).

**Verdict.** The additions add a few genuinely useful fixed columns (exchangeable cation, linkage, sequence
composition) and steadier compound names, but cost ~24% more and were less consistent run to run, and the vocabulary
junk caused new misnamings. Net accuracy is about even; for Sam-type papers the DUPE pack's value would come from a
cleaned vocabulary and a keyword trigger on product_structure (oligomer / linkage) rather than always running.

**Fixed after this run:** Suggest additions now filters its compounds like Find compounds (no panel letters, single
bases, DNA/RNA, enzymes, dyes, kits; 'X/Y' split; 2' and 2' treated as one) -- the junk above can't be suggested again.
