# Cost pass on the module structure (2026-11-09)

Mickey: modules send the model less irrelevant material, but papers cost more overall, because more parameters are
correctly written to the output. He asked for another optimisation pass with live runs on previously tested papers,
aimed at row planning and output tokens, with the pack and model settings noted for every run.

## Setup

- **Pack, every run:** Prebiotic chemistry, the existing pack that best fits these papers. Since this round it links
  Analysis methods, Solution chemistry, Kinetics, Wet-dry cycling, Peptides and oligomers, Mineral surfaces and Flow
  reactor. A pack drafted from these papers can't be scored against the hand-checked references, whose columns are
  Prebiotic's.
- **Settings, every run:** prompt caching on, one reading, no batch mode, PubChem off, no remembered variables.
- **Model profiles:**
  - Standard: Sonnet 5.5 everywhere; Haiku for the paper's details.
  - Balanced: Sonnet plans the rows; Haiku for every other step.
  - Economy: Haiku everywhere.
- **Papers:**
  - Five references, scored against their expected CSVs: eder1994, faisal2005, kim2017, kim2019, truman2024.
  - Three cost-stress papers without a reference: Hirakawa 2025 (51 rows), Ferris 1993 (clays, so it uses the
    mineral and linkage steps) and Islam2003 (flow reactor). Each is scored against its own baseline run, so their
    accuracy figures are consistency, not correctness.
- **Prices:** Sonnet 5.5 $2 / M input, $10 / M output, $2.50 / M cache write, $0.10 / M cache read.

## Where the money went (baseline, Standard)

eder1994, $0.311:

| Part | Share |
|---|---|
| Output | 49% |
| Every step's uncached input (its instructions and the row plan) | 26% |
| Writing the paper to the cache (once, while planning the rows) | 22% |
| Cache reads | ~3% |

Inside the output:
- **Chemistry:** field names 26%, set labels 18%, sample labels 5%. A set label such as "Na+ 3.33 mol dm-3, 81 C"
  was repeated on every table row.
- **Conditions and analysis:** quotes 25–31% (already only 7–9 words on average), sources 12%, field names 17–20%.
- **Row planning:** per-sample sources 19% (mostly "Table 1, row 3"), excluded data 15%.

The row plan went to every step as indented JSON with every field, and it was uncached: 1.8K–8.6K characters
before indentation, four to six times per paper.

## Changes

1. **A compact row plan for the extraction steps** (`structure_plan.step_plan_json`): one line of JSON, only the
   fields steps use, an `id` per set ('S1') and sample ('S1.2'). eder1994's plan is 5.4K characters instead of 11.6K.
2. **Steps answer with the ids.** One rule at the top of the plan, plus the prompt lines that asked for exact labels.
   The app puts the labels back (`expand_ids`, in `api_client.call_structured`, for every step and every reading)
   before anything reads the answer. Answers recorded with labels still replay unchanged.
3. **Row planning writes less:**
   - a sample's `src` only when it is somewhere other than its set's (data_location falls back to the set's);
   - excluded-data reasons at most 8 words;
   - notes one sentence, only for a real ambiguity.
4. **Chemistry:** the model's own mM conversion only for mass-per-volume amounts. The app converts molar units
   itself.
5. **Balanced profile:**
   - Row planning (Sonnet) no longer writes a cache. A cache is per model, so the Haiku steps could never read it.
   - One one-token Haiku request writes the paper's cache before the parallel Haiku steps start. Before, each of them
     wrote its own copy at the same time.
6. **Robustness, found in a Balanced run:** Haiku left out a species' value twice (truman2024), which failed the whole
   chemistry step. The species fields keep their required place in the schema sent to the model but have defaults in
   the app (value missing = not given, confidence missing = "low", so it is flagged).

Also measured and left alone:
- **A higher Kinetics trigger threshold.** faisal2005 has 1 mention and real values; truman2024 has 3 mentions and none.
- **Tighter quote limits.** Quotes are already short, and shorter ones would weaken the check that they're found in
  the paper.
- **Making confidence or unit optional.** An earlier run showed that optional fields get skipped.
- **Trimming the reference list.** The heading is detected in only 3 of 8 papers. It is 27% of eder1994's text, but
  cited-data detection relies on it.

**Accuracy and consistency:**
- No reference value was lost to the ids. Every reference's accuracy equals or beats its baseline in at least one round.
- The cost-stress papers' consistency with their baseline runs ranges from 40% to 86%. These are run-to-run
  differences, checked one by one:
  - Hirakawa's analysis step skipped LC-MS/MS in round 1 ("other experiments") and found it again in round 2.
  - Islam2003 named the technique "HPLC" instead of "RP-HPLC", so every setting lands in a column with another name.
  - Islam2003 recorded its gas treatment as reservoir degassing rather than as the headspace gas, which is arguably
    the better reading.

## What's left

- **Standard** now spends about 40% of a paper on writing the paper to the cache plus row planning, and about 45% on
  output. What remains is the extraction itself (values, quotes, sources). Reducing it further would mean giving up
  provenance (quotes) or accuracy.
- **Balanced** now spends 60–85% of a paper on Sonnet planning the rows. Its extraction steps cost $0.001–0.008 each.
- **Economy** is about 15× cheaper than Standard, at 8–9 points lower reference accuracy (kim2019 is the outlier at
  69%). Reading values three times (Economy × 3) was measured on 2026-11-03 at about Standard's accuracy.

Live cost of this pass: $2.19 (baseline) + $1.99 + $2.00 (Standard rounds) + $0.94 + $0.76 (Balanced) + $0.15
(Economy) = **$8.03**.
