# History index

Every section of the project's dated history, in order: decisions, measurements and what was built. The files
are written for agents and kept verbatim; search them for a keyword (`grep -n KEYWORD docs/history/*.md`) rather
than reading them whole. Later sections supersede earlier ones. A new round's write-up goes at the end of the
current month's file (start `YYYY-MM.md` in a new month), with one line here.
